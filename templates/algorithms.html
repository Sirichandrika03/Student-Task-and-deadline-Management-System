Algorithm 04

Binary Max-Heap Priority Queue for Task Scheduling

Prioritizes high-urgency tasks using a complete binary tree where parent priority ≥ children. Score mapping: High=3, Medium=2, Low=1. Tie-Breaker: If two tasks share equal priority, the task with the nearest deadline appears first.

Time Complexity
Insert (Sift-Up): O(log n)
Extract Max (Sift-Down): O(log n)
Peek Max: O(1)
HeapSort Schedule: O(n log n)

Algorithm 05

Divide & Conquer Merge Sort for Deadlines

Recursively divides task arrays into halves until atomic subarrays of size 1, then merges them in linear time based on chronological deadline comparisons.

Time Complexity
Best Case: O(n log n)
Average Case: O(n log n)
Worst Case: O(n log n)
Auxiliary Space: O(n)

Algorithm 06

Binary Search on Sorted Unique Task IDs

Pre-sorts task IDs in ascending order, then repeatedly halves the candidate space by evaluating the midpoint element against target ID.

Time Complexity
Best Case: O(1) [Midpoint hit]
Average Case: O(log n)
Worst Case: O(log n)
Space: O(1) iterative
